# Green Transport Patent Intelligence Pipeline

A full end-to-end data pipeline analysing **141,124 active green transportation patents** (CPC Y02T) granted by the USPTO from 1976 to 2025.

**Focus:** Climate change mitigation in transportation — covering electric vehicles, hybrid engines, fuel cells, aviation propulsion, maritime shipping, and charging infrastructure.

---

## Pipeline Architecture

```
USPTO PatentsView (manual download → data/raw/)
↓
00_check_raw.py            — validates raw file columns
↓
02_clean.py                — filters Y02T patents, cleans data
↓
02b_data_quality.py        — quality checks, fixes geocoding errors
↓
03_load_db.py              — loads 4 tables into SQLite (patents.db)
↓
04_analyze.py              — runs 7 SQL queries, exports CSVs
↓
04b_advanced_analysis.py   — diagnostic & predictive analysis
↓
05_report.py               — JSON report + summary CSV
↓
run_pipeline.py            — captures all output to console_report.txt
↓
dashboard/app.py           — Streamlit interactive dashboard (8 pages)
```

## Quickstart

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/green-patent-pipeline.git
cd green-patent-pipeline
```

### 2. Create virtual environment and install dependencies

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Download raw data files (REQUIRED)

> The raw data files total ~13 GB and cannot be stored on GitHub.
> They must be downloaded manually before running the pipeline.

**Instructions:**

1. Go to: <https://data.uspto.gov/bulkdata/datasets/pvgpatdis>

2. Download and unzip these 6 required files:

   | File | Size | Description |
   |------|------|-------------|
   | `g_patent.tsv` | ~1.1 GB | Core patent info |
   | `g_patent_abstract.tsv` | ~5.9 GB | Patent abstracts |
   | `g_inventor_disambiguated.tsv` | ~2.2 GB | Inventor names & locations |
   | `g_assignee_disambiguated.tsv` | ~1.1 GB | Company/assignee names |
   | `g_location_disambiguated.tsv` | ~9 MB | City, state, country lookup |
   | `g_cpc_current.tsv` | ~3.2 GB | CPC classification codes |

3. For citation analysis (enables PageRank-style company ranking):

   | File | Size |
   |------|------|
   | `g_us_patent_citation.tsv` | ~2 GB |

4. Place all `.tsv` files into: `data/raw/`

   ```
   data/raw/
   ├── g_patent.tsv
   ├── g_patent_abstract.tsv
   ├── g_inventor_disambiguated.tsv
   ├── g_assignee_disambiguated.tsv
   ├── g_location_disambiguated.tsv
   ├── g_cpc_current.tsv
   └── g_us_patent_citation.tsv (optional)
   ```

### 4. Run the full pipeline

```bash
python3 scripts/run_pipeline.py
```

This executes all 6 pipeline steps in sequence (~15-20 minutes):

| Step | Script | Output |
|------|--------|--------|
| 1 | `02_clean.py` | `data/clean/clean_*.csv` (4 files) |
| 2 | `02b_data_quality.py` | Quality-checked CSVs, geocoding fixes logged |
| 3 | `03_load_db.py` | `patents.db` (913.9 MB SQLite database) |
| 4 | `04_analyze.py` | 9 analysis CSV files in `output/` |
| 5 | `04b_advanced_analysis.py` | Citation rankings, forecasts, momentum analysis |
| 6 | `05_report.py` | `report.json` + `pipeline_summary.csv` |

**Output log:** `output/console_report.txt` (complete terminal output)

### 5. Launch the dashboard

```bash
streamlit run dashboard/app.py
```

Open browser to **<http://localhost:8501>**

## Analysis Types

### Descriptive Analysis (Dashboard Pages 2-5)

What happened? Overview of patent activity by geography, time, and actors.

- Patent trends 1976-2025
- Top inventors and companies
- Country distribution (inventor vs company location)

### Diagnostic Analysis (Dashboard Page 6)

Why did it happen? Root causes and drivers of observed patterns.

**Citation-Weighted Company Rankings** (addresses lecturer feedback)

- Traditional ranking: patent count only (shallow)
- New ranking: forward citation count (quality-based)
- Methodology: Mimics Google PageRank — highly-cited patents = foundational breakthroughs
- Files: `top_companies_by_citations.csv`, `top_companies_by_avg_citations.csv`, `rank_comparison.csv`

**Technology Emergence Detection**

- Identifies which Y02T subcategories are accelerating
- Compares 2015-2019 vs 2020-2024 growth rates
- Road vehicles declining (-11.8%), aviation propulsion growing (+16.4%)
- File: `subcategory_emergence.csv`

**Policy Correlations**

- External events mapped to patent spikes
- Toyota Prius era (2005), Paris Agreement (2015), EU Green Deal (2020)
- References: IEA, ICAO, IMO, EC

### Predictive Analysis (Dashboard Page 7)

What will happen? Forward-looking insights and forecasts.

**Patent Trend Forecasting** (Machine Learning)

- Model: Linear regression trained on 2014-2024 data
- Forecast period: 2025-2030
- Predicted activity: ~7,500 patents/year (relatively stable)
- R² score: 0.003 (simple baseline model)
- File: `patent_forecast_2030.csv`

**Country Momentum Index** (Predictive Analytics)

- Compares market share shifts: 2014-2018 vs 2019-2024
- Rising stars: China (+2.44%), Canada (+0.99%)
- Stable: USA (+0.87%), Japan (-0.01%)
- Predicts which countries will dominate future innovation
- File: `country_momentum.csv`
